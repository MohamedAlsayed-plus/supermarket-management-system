# نظام إدارة السوبر ماركت

واجهة سطح مكتب **عربية بالكامل** مبنية بـ PySide6، تتصل مباشرةً بقاعدة بيانات **Microsoft SQL Server** (SupermarketDB). تدعم إدارة الأصناف والمنتجات والعملاء، وإنشاء الفواتير مع خصم المخزون، وعرض التقارير.

## المتطلبات

- Windows مع Python 3.11 أو أحدث.
- SQL Server (Express أو أي إصدار) متاح من الجهاز، مع صلاحية القراءة/الكتابة على `SupermarketDB`.
- برنامج **ODBC Driver 17 أو 18 for SQL Server** مثبّت (essential).
- SSMS اختياري لتنفيذ سيناريو SQL يدويًا.

## التثبيت

من مجلد المشروع:

```powershell
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## إعداد قاعدة البيانات

لديك طريقتان:

1. افتح `sql/SupermarketDB.sql` في SSMS ونفّذه (ينشئ قاعدة البيانات والجداول والبيانات التجريبية).
2. من التطبيق: في نافذة الاتصال اضغط **«تهيئة قاعدة البيانات»**. ⚠️ هذا يحذف الجداول الخمسة ويعيد إنشائها، ويفقد أي بيانات موجودة.

## التشغيل

```powershell
python -m app.main
```

يعمل أيضًا: `python app/main.py`.

## الاتصال

عند بدء التطبيق تظهر نافذة الاتصال:

- **اسم السيرفر**: مثل `localhost\SQLEXPRESS` أو `.` أو اسم سيرفر بعيد.
- **قاعدة البيانات**: `SupermarketDB` افتراضيًا.
- **طريقة المصادقة**:
  - مصادقة Windows: تستخدم حساب مستخدم Windows الحالي (`Trusted_Connection`).
  - مصادقة SQL Server: اسم مستخدم وكلمة مرور (مثل `sa`).
- **اختبار الاتصال** و**تهيئة قاعدة البيانات** متاحان قبل الدخول.

تُحفظ الإعدادات في `config.json` (غير مدرج في Git). كلمة المرور تُحفظ فقط إذا فعّلت «حفظ كلمة المرور»؛ يُنصح بذلك على جهازك المحلي فقط لأنها تُخزَّن كنص عادي.

## الواجهة

- **المبيعات**: اختيار العميل (أو عميل نقدي)، إدخال المنتج بالاسم أو الباركود، الكمية وسعر الوحدة، ثم حفظ الفاتورة. الحفظ يتم في معاملة واحدة: إدراج الفاتورة + تفاصيلها + خصم الكميات من المخزون، مع منع البيع بأكثر من المتوفر.
- **المنتجات**: إضافة/تعديل/حذف وبحث بالاسم أو الصنف أو الباركود.
- **الأصناف** و**العملاء**: إضافة/تعديل/حذف مع منع حذف أي سجل مرتبط بسجلات أخرى.
- **التقارير**:
  - جدول المبيعات مع فلترة بالتاريخ والعميل، تفاصيل الفاتورة عند اختيارها، وإجمالي المبيعات.
  - حذف فاتورة مع إعادة الكميات إلى المخزون.
  - تقرير المخزون مع خيار عرض المنتجات منخفضة الكمية فقط.

## هيكل المشروع

```text
demo/
├── app/
│   ├── main.py            # نقطة التشغيل
│   ├── main_window.py     # النافذة الرئيسية والتبويبات
│   ├── login_dialog.py    # إعداد الاتصال وتهيئة قاعدة البيانات
│   ├── db.py              # الاتصال، المعاملات، رسائل الأخطاء، تشغيل سيناريو SQL
│   ├── repository.py      # كل استعلامات CRUD والتقارير
│   ├── config.py          # قراءة/حفظ الإعدادات
│   ├── formatting.py      # تنسيق الأرقام والتواريخ
│   ├── rtl.py             # اتجاه RTL والخط العربي ونوافذ الرسائل
│   └── tabs/              # الأصناف، المنتجات، العملاء، المبيعات، التقارير
├── sql/SupermarketDB.sql  # سيناريو المخطط والبيانات التجريبية
├── config.example.json
├── requirements.txt
└── README.md
```

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «لم يتم العثور على برنامج ODBC» | ثبّت ODBC Driver 17/18 for SQL Server وأعد تشغيل التطبيق |
| «فشل تسجيل الدخول» | راجع اسم المستخدم/كلمة المرور أو اختر مصادقة Windows |
| «تعذّر فتح قاعدة البيانات» | نفّذ `sql/SupermarketDB.sql` أو استخدم زر التهيئة |
| «تعذّر الوصول إلى السيرفر» | تأكد أن خدمة SQL Server تعمل وأن اسم السيرفر صحيح |

كل استعلامات البرنامج تستخدم معاملات مُرقّمة (parameters) وليس دمج نصوص، والأسعار تُعامل كـ `Decimal` لتجنب أخطاء الفاصلة العائمة.
